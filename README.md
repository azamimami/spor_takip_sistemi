# Spor Takip Sistemi
Python ile geliştirilmiş terminal tabanlı bir spor takip sistemidir. Sistem, sporcuların kayıtlarını,
antrenmanlarını ve performans takibini nesne yönelimli programlama (OOP) yapısı ile yönetir.

# Sistem Yapısı

# Sporcu Modülü

* Sporcu ekleme
* Sporcu listeleme
* Sporcu silme
* Kilo ve boy bilgisi yönetimi
* İlerleme kaydı (kilo değişimi takibi)

# Antrenman Modülü

* Antrenman ekleme
* Antrenman türü tanımlama
* Süre takibi (saat ve dakika)
* Antrenman listeleme

# Takip Modülü

* Sporcu ve antrenman eşleştirme
* Kalori takibi
* Tarih bazlı kayıt oluşturma
* Aktivite geçmişi görüntüleme

# Kullanılan Teknolojiler

* Python 3
* Nesne Yönelimli Programlama (OOP)
* datetime modülü
* List veri yapısı
* Terminal tabanlı kullanıcı arayüzü
* In-memory veri yönetimi (veritabanı kullanılmaz)


# Sistem Mantığı

* Sporcular sisteme kayıt edilir
* Antrenmanlar tanımlanır
* Sporcu ile antrenman eşleştirilerek takip oluşturulur
* Kalori ve süre bilgileri kaydedilir
* Sporcu gelişimi (kilo değişimi) takip edilir
